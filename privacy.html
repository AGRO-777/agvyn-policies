Privacy Policy

Effective: September 9, 2026 · Last updated: September 9, 2026

AGVYN (“we”, “us”, “our”) is a Discord bot providing moderation, utility, giveaway, ticket, AFK, timezone, message-management, and entertainment features.

1. Information We Process

  • Discord user ID
  • Discord username/display name
  • Server ID and channel ID
  • Message IDs and, when required by enabled features, message content
  • AFK status and reason
  • Timezone preference
  • Giveaway configuration and entrants
  • Ticket and moderation-related information
  • Bot configuration/settings for a server

AGVYN does not intentionally request passwords, Discord account tokens, payment information, or other sensitive credentials.

2. How We Use Information

Information may be used to provide commands and features, store server configuration, operate giveaways and tickets, provide message logging/snipe and moderation features, prevent abuse, troubleshoot problems, and maintain AGVYN.

3. Message Content

Some features require message-content access, such as message logging and snipe. Message content is processed only where necessary for those features and is not sold or used for advertising.

4. Data Storage

AGVYN may store configuration and feature-related information so settings continue to work after restarts. Information is retained only as reasonably necessary for the feature or legitimate operational purposes.

5. Data Sharing

We do not sell personal information or intentionally share it with advertisers. Information may be processed by third-party services when necessary to operate AGVYN or its infrastructure.

6. Data Removal

Server administrators may request deletion of AGVYN's stored server configuration and associated bot data. Users may request deletion of information associated with their Discord user ID where applicable. Requests can be made through the official AGVYN support channel/server.

7. Children's Privacy

AGVYN is a Discord application. Users must comply with Discord's age requirements and policies. AGVYN does not knowingly request unnecessary personal information from users.

8. Security

We take reasonable measures to protect information processed by AGVYN, but no online service can guarantee absolute security.

9. Changes

This policy may be updated when AGVYN's features, data practices, or legal requirements change.

10. Contact

For privacy questions or data deletion requests, contact the AGVYN team through the official AGVYN support server.
